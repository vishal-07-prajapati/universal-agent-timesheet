---
description: Generate daily EMS / timesheet entries from today's conversations, git commits, or tickets.
---

Run `python ems_cli.py --today` or execute the `generate_timesheet` tool to inspect today's work activity and output formatted timesheet entries matching the user's saved preferences.

If this is the user's first time running `/ems`, run `python ems_cli.py --setup` to ask them for their preferred sample format, character limits, and end-of-day automation preference.
